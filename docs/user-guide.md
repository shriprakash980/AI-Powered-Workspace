# DevPilot AI — User Guide & Viva Reference

## 1. Quick Start Workflow
1. **Explore Landing Page:** Navigate features, developer workflow, and architecture stack.
2. **Account Onboarding:** Create an account via `register.html` or sign in via `login.html`.
3. **Dashboard Management:** View platform metrics, search projects, create a new project via template modal (`Blank`, `HTML/CSS/JS`, `Java Spring Boot`, `Node.js`, `Python`).
4. **Workspace Operations:**
   - Browse files in the tree view. Expand folders, create files/folders.
   - Edit code in Monaco Editor with syntax highlighting and tabs.
   - Leverage AI Assistant: Generate code, explain logic, debug issues, refactor, run tests.
   - Inspect unified diffs and apply or reject AI modifications.
   - Run safe commands in the terminal with isolated output.
   - Preview web apps live in the sandboxed preview tab.
5. **Deployment & Git:** View commit history, link GitHub repositories, and trigger automated builds.
